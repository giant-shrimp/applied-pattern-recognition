# 01 基礎理論 演習レポート

「第I部：基礎理論」の演習レポートで使用したプログラムです．

## 内容

`report_figures.py` は，手計算で求めた答えの検算と，解答用の図の描画を行います．

- 問題1：2クラスのクラス依存確率密度を2次元正規分布でモデル化し，ベイズ識別の決定境界を求める問題．事前確率，平均ベクトル，共分散行列（最尤推定値）を計算し，導出した決定境界（楕円）の上で2つの識別関数の値が一致することを確認して，決定境界とパターンを描画します．
- 問題2：体積不変の正規化とKL展開（主成分分析）の問題．スケーリング係数，正規化後のパターン，経験共分散行列の固有値・固有ベクトル，1次元へ変換した後のパターンを計算し，数直線上に描画します．

## 配布されたサンプルコード

`distributed/sample.py` は，講義で配布されたサンプルコード（2次元正規分布の等確率密度線と決定境界の描画）です．配布されたものを変更せずにそのまま置いています．実行には NumPy，Matplotlib に加えて SciPy が必要です．

## 実行方法

```
pip install numpy matplotlib
python report_figures.py
```

検算結果が標準出力に表示され，図が `output/` に保存されます．

- `output/problem1_decision_boundary.png`：問題1の決定境界とパターン
- `output/problem2_number_line.png`：問題2の変換後のパターン（数直線）
