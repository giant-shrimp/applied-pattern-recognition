# applied-pattern-recognition

大学院 専門科目「パターン認識応用」（Applied Pattern Recognition）のレポートで使用したプログラムをまとめたリポジトリです．

## 構成

レポートごとにフォルダを分けています．

| フォルダ | 内容 |
|---|---|
| [01_basic-theory](01_basic-theory) | 基礎理論 演習レポート：正規分布によるベイズ識別の決定境界，体積不変の正規化とKL展開 |

## 実行環境

Python 3 と，各フォルダの README に書かれたライブラリ（NumPy，Matplotlib など）が必要です．
